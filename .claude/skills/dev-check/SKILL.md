# 개발 점검 (dev-check)

코드를 커밋하거나 push하기 전에 아래를 순서대로 실행한다. 하나라도 실패하면 원인을 고친 뒤 처음부터 다시 실행한다.

1. 린트: `npm run lint`
2. 타입 검사: `npx tsc --noEmit`
3. 빌드: `npm run build`

## 참고
- 이 프로젝트의 Next.js는 최신 버전이라 API가 학습 지식과 다를 수 있다. 코드를 쓰기 전에 `node_modules/next/dist/docs/`의 관련 문서를 확인한다 (`AGENTS.md` 참고).
- Supabase 환경변수가 없어도 빌드는 통과해야 한다. 빌드 시점에 환경변수가 필요한 코드를 넣지 않는다.
- 결과는 단계별 통과/실패로 짧게 보고한다.
